# Olist 巴西电商平台黑五活动效果分析

基于 Olist 巴西电商平台真实交易数据，对 2017 年黑色星期五活动进行复盘分析。

---

## 项目文件

| 文件 | 说明 |
|---|---|
| `blackfridaycampaignperformanceevaluation.ipynb` | 主分析 Notebook，包含完整分析过程与可视化 |
| `olist_black_friday_performance.twb` | Tableau 交互式仪表盘源文件 |
|`blackfriday_dashboard.html` | [Antvis Skill](https://github.com/antvis/chart-visualization-skills) 辅助搭建报表 |
---

## 数据集

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)（Kaggle）

共 9 张关联表，约 10 万订单，时间跨度 2016–2018 年。

---

## 分析工具

- Python（pandas、matplotlib、seaborn） · Kaggle Notebook
- Tableau Public

---

## 分析窗口

| 时期 | 时间范围 |
|---|---|
| 基准期 | 2017-10-02 ~ 2017-11-05 |
| 预热期 | 2017-11-06 ~ 2017-11-19 |
| 活动期 | 2017-11-20 ~ 2017-11-26（黑五当周）|
| 活动后 | 2017-11-27 ~ 2017-12-03 |
